# Dados e escopo

O código original gera esta base artificialmente. Os valores não descrevem pessoas, empresas ou clientes reais.

O CSV existente foi preservado. A revisão não substitui a amostra por dados de clientes.

Arquivo: `data/simulated_data.csv` · 100 linhas · 3 colunas.

| Campo | Tipo no CSV | Valores ausentes | Papel na análise |
|---|---|---:|---|
| feature_1 | float64 | 0 | Atributo |
| feature_2 | float64 | 0 | Atributo |
| target | float64 | 0 | Alvo |

Identificadores são artificiais; os nomes das colunas foram mantidos para facilitar a reprodução.

O alvo foi gerado de forma independente dos atributos. Eventuais diferenças de desempenho neste recorte são variação amostral, não evidência de capacidade preditiva em produção. Não há datas, lojas ou vendas; esta base não permite previsão de vendas.
